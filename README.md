# LinguaTranslate 🌐

LinguaTranslate is a simple web-based language translation tool developed as part of the CodeAlpha Artificial Intelligence Internship.

## Features

- Translate text from one language to another
- Select source and target languages
- Simple and user-friendly interface
- Copy translated text with one click
- Supports multiple languages
- Translation is processed using a translation API

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Translation API
